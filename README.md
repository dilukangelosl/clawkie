# Clawkie

A walkie-talkie for your Claude Code agents. One MCP server that lets Claude Code sessions on different machines (laptop, VM, servers) working on the same project see what each other is doing and pass prompts, results, and status updates to each other, so you stop copy-pasting between terminals.

> Status: early design.
